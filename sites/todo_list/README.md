# Todo List

一个基于 React + Vite 的网页版待办事项提醒工具。

## 功能

- 添加、编辑、完成和删除待办事项
- 设置备注、提醒时间和优先级
- 按全部、进行中、已逾期和已完成筛选
- 使用浏览器 `localStorage` 持久化数据
- 页面内到期提醒
- 支持浏览器系统通知
- 响应式布局，适配桌面和移动端

## 本地运行

```bash
npm install
npm run dev
```

打开终端中显示的本地地址即可使用。

## 质量检查

```bash
npm test
npm run lint
npm run build
```

## 技术栈

- React 19
- Vite
